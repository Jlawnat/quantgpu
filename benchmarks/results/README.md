# Benchmark Results

This directory stores reproducible benchmark outputs generated by QuantGPU.

## Files

- `monte_carlo_numpy.csv` — NumPy CPU Monte Carlo benchmark results.

## Policy

Raw benchmark results are append-only.

Each row records:
- execution timestamp
- backend
- device
- Python version
- NumPy version
- workload size
- timing configuration
- latency
- throughput
- estimated option value
- Black–Scholes reference value
- numerical error
- Monte Carlo standard error
- random seed

Headline performance results should be derived from saved benchmark data rather than copied manually from terminal output.
